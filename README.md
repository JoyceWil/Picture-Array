# Picture Array

还在用Visio简单的排列和裁剪吗？还在为一张图包含几十上百个可视化结果而心烦吗？Picture Array 是一个面向论文实验结果的浏览器端图阵排版工具，用于整理同一数据集在不同模型下的可视化结果，并导出适合论文使用的图像或矢量 PDF。

在线使用：<https://picturearray.joyce2001.cn/>

## 功能概览

- 素材库：批量导入 PNG、JPG、JPEG、WEBP 等图片，支持拖拽、双击填充、重命名和删除。
- 非破坏性预处理：保持原图比例，支持输入 X/Y/W/H 或拖动四个角进行裁剪。
- 处理结果入库：裁剪结果作为新素材保存，原始素材保持不变；同一张原图可以生成多个裁剪结果。
- 裁剪模板：保存、调用和删除常用裁剪范围，可应用于当前素材或全部素材。
- 图阵画布：自定义行列数、间距、画布宽度、最小高度、边距和原图缩放比例。
- 标签设置：列标签置于底部，行标签置于左侧并可旋转；支持统一位置、字体大小、加粗、斜体和 LaTeX 公式。
- 局部放大：统一开关控制整行局部图，原图尺寸保持不变；局部图默认为正方形，可设置数量（1–4，默认 2）和边框颜色。
- 工作空间模板：使用浏览器 IndexedDB 保存和恢复素材、裁剪、布局、标签及局部放大设置。
- 导出：支持按实际画布尺寸导出矢量 PDF 和高分辨率 PNG；PDF 中的文字、标签、边框和 ROI 保持矢量，原始图片以位图嵌入。

## 基本工作流

1. 将实验结果图片导入素材库。
2. 在预处理区域裁剪图片，并将裁剪结果保存为新素材。
3. 设置图阵的行列数，将素材拖入对应单元格。
4. 编辑行标签、列标签、画布尺寸和图片比例。
5. 开启整行局部放大，调整 ROI、局部图数量和边框颜色。
6. 保存工作空间模板，或导出 PDF、PNG 和项目配置 JSON。

## 数据与隐私

- 图片预处理和排版在浏览器本地执行，应用不会主动把素材上传到服务器。
- 草稿使用 `localStorage` 保存，裁剪模板和工作空间模板使用 IndexedDB 保存。
- 浏览器数据按域名、浏览器和设备隔离；清除网站数据会删除本地模板。
- 导出的项目配置 JSON 主要包含布局和元数据，不包含原始图片二进制，不能单独作为完整图片备份。

## 导出格式

| 格式 | 说明 |
| --- | --- |
| PDF | 使用自定义画布尺寸；文字、标签、边框、ROI 和 LaTeX 保持矢量，图片按原始像素嵌入。 |
| PNG | 支持 2× 标准和 3× 高清输出。 |
| 项目配置 JSON | 导出当前布局、标签、裁剪和局部放大设置，便于记录或迁移配置。 |

## 技术栈

- React 18
- TypeScript
- Vite
- KaTeX / MathJax
- jsPDF / svg2pdf.js
- html-to-image
- IndexedDB
